# invoice_system
## 概要
- 請求書を自動作成するマクロです
## 実行結果
![実行結果](image/result.png)
## 機能
- 該当する顧客名のデータすべてを請求書シートに転記できます。
- B2セルが空欄の場合、エラーが表示されます。
- B2セルの顧客名が売上データに存在しない場合、エラーが表示されます。
- 請求書作成の図形をクリック（ボタンになっています）するとマクロが実行されます。
## 実行方法
1. ワークシート「請求書」B2セルの顧客名をプルダウンで選択（売上データ連動）
2. 「請求書作成」の図形をクリック
3. 該当する顧客名のデータが下の表に転記されます
## 使用技術
- クラスモジュール
- initメソッド
- インスタンス変数を参照したFunction
- Private変数（カプセル化）
## 工夫した点
- クラスモジュールを用いて、保守性を向上させました。
- 標準モジュールのコード量、重複コードを減らすようにしました。
